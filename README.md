# pnn.c
A simple 1D Probability Neural Network written in C for educational proposes. 

## Quick start
### Clone the repo
```
git clone https://github.com/MB-Bidram/pnn.c.git
cd pnn.c
```
### Compile
#### GNU GCC
```gcc main.c -o pnn.exe -O2```
#### Clang
```clang main.c -o pnn.exe -O2```
#### MSVC
```cl /O2 /TC hello.c```
